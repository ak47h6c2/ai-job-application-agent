# 智联工作职责串填检查（2026-10-05 至 2026-10-06）

目标：用户提供的智联校园 `resume2` 页面。用户要求模拟填写并修复阿尔派“主要工作职责和业绩”错填，且明确确认阿尔派属于实习。

原标签页含未保存的阿尔派工作草稿，测试使用独立标签页。未修改资料库，未点击网站保存或投递，未上传文件，未测试薪资或证明人资料。本文不记录电话、联系人等信息。

## 旧版现场复现

独立页面编辑阿尔派已保存条目，已有公司、职务及任职日期，职责为空。点击插件一键填写后，职责框实际出现“AI求职申请助手”项目介绍，与本地资料库第一段项目描述逐字一致，既不是阿尔派职责，也不是其他工作职责。测试草稿随后取消，没有保存。

现场结构导出进一步确认真正的页面触发原因：上方已保存记录的证明人职务“项目经理”被当成项目板块标题，导致阿尔派的工作单位、职务及职责分别识别为项目所属单位、角色和项目描述。没有填写或修改证明人联系方式。

代码检查还发现旧站点字段记忆优先于板块识别，`主要工作职责和业绩 -> projects.description` 可以稳定重现同样错误。没有直接读取浏览器隐藏存储；这属于另外已复现并修复的错误路径。

另一个独立问题是工作编辑框按资料顺序选经历，没有根据已有公司和日期绑定整段资料。资料库第一段工作不是阿尔派时，即使正确识别为工作职责，也可能填另一家公司的内容。

## 修复

- 标题匹配不再把“项目经理”等短词当成板块名；排除 Element UI 等组件中已保存的字段值，避免资料内容改变后续表单的板块。
- 新的手动字段选择使用“板块、标题、标签”共同记录；旧记忆与当前板块冲突时重新识别。兼容原本正确的旧映射，保留新明确选择和跳过功能。
- 工作编辑框按已有公司、起止月份选择唯一经历；同公司的不同任职期间使用日期区分，必要时用职务进一步区分。没有唯一对应记录时留空并提示核对，不借用其他工作。
- 公司匹配仅容许可选的“(中国)”限定词；保留城市和分支名称，不把北京分公司与上海分公司当成同一条。
- 填写结果增加折叠的“已填资料”，工作字段显示来源公司。
- 从网页读取资料时同样按公司及日期匹配，避免公司限定词引发重复新增；多个工作记录都匹配时阻止导入并提示补充日期或职务。
