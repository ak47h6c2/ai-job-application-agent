# 全面检查与修复（2026-10-08，插件 v0.4.22）

## 检查范围

通读 `backend/app`、`extension/src`、`frontend/src`、`shared` 全部代码，按逐行、删除行为、跨文件调用、语言陷阱、复用、简化、性能、修复深度几个角度检查，共找到 15 个问题。其中 4 个用临时脚本复现或量化：

- 勾选框：「本人承诺无违法违纪行为」对 `basic.hasCriminalRecord` 得 71 分（门槛 45）。
- 合并：网页端改经历 1、插件改经历 2，冲突自动合并结果为 `[A(已改), B, B(含单位类别)]`。
- 字数：「不少于300字」「300字以上」被解析成上限 300，「200-500字之间」只取到 500。
- 识别耗时：单个栏位分类约 0.9 ms（186 个字段、1687 个匹配词）。量级不大，未单独改动。

## 问题与修复

| # | 问题 | 修复 |
|---|------|------|
| 1 | 承诺 / 同意类、否定措辞的勾选框会被自动勾选或反向勾选；用户自己的勾在再次填写时被改回 | 这类勾选框不参与识别；已勾选或被用户取消过（`data-jaf-ticked`）的勾选框视为已有值 |
| 2 | 冲突合并在同一栏目两边都改时复制出重复经历 | 按条目三方合并，双方都改的条目按字段合并；比较时忽略键的顺序 |
| 3 | 最低字数被当作上限 | 先剔除最低字数提示再找上限；最低字数单独上报并传给 AI（`min_length`） |
| 4 | AI 草稿超出字数时被从中间硬切，富文本框不处理字数 | 前端、后台统一按句末截断；contenteditable 也按上限截断并标记 |
| 5 | 添加经历后的行内保存可能点到页面级「完成 / 确认」 | 只在这段经历自己的编辑区内找按钮，且只认「保存 / 确定 / save / ok」 |
| 6 | 关闭页面时 keepalive 保存超过 64KB 必然失败，并且无论成败都清掉未保存标记 | 页面隐藏时立即保存；有未保存修改时离开前询问；超限不发请求；正在进行的保存也补发 keepalive |
| 7 | 启动按钮检测在每个网站上反复全页扫描、强制排版，永不停止 | 单次线性扫描文本节点；用 TreeWalker 取页面文字；按钮出现或设置关闭后停止观察 |
| 8 | 每个网页的每个框架加载时都拉取完整资料；自动读取作用于所有网站 | 只在招聘页面（或用过面板的页面）开始输入时加载资料；没有资料上下文时不做自动读取 |
| 9 | 后台出错（如 503）也静默回退到旧缓存；422 显示为 `[object Object]` | 只有连接不上或超时才用缓存，其他错误在面板和弹窗显示原因；校验错误转成文字 |
| 10 | 岗位页一律按 UTF-8 解码；内网检查只看字面 IP，跳转不检查 | 按响应头 / meta 编码解码，再依次试 UTF-8、GB18030；解析域名并检查每次跳转 |
| 11 | 简历识别的文件框允许 .docx/.doc，后台只支持 PDF 和文本 | 后台用 zipfile 解析 .docx（含表格），.doc 提示另存；文件框改为 PDF / DOCX / TXT / MD |
| 12 | 最近一段学历「至今」时，毕业时间取了上一段学历的 | 最近一段学历仍在读时毕业时间留空 |
| 13 | 面板每次刷新整页重建，滚动位置回到顶部，每行生成约 600 个选项 | 刷新前后保持滚动位置；「填入…」下拉在获得焦点或按下时才生成选项 |
| 14 | multipart 接口可被任意网站跨站调用（上传附件、消耗 AI 额度） | 后台拒绝来自 Web UI 和插件以外的浏览器来源的写请求；读取和无 Origin 的本地调用不受影响 |
| 15 | 通过搜索 / 滚动选中的区间档位没有「请核对」 | 三条选择路径统一走同一个判断；删除未使用的 `seen` 变量 |

另外修复：弹窗发送命令失败时会立即关闭，看不到原因。现在失败时保持打开。

## 新增测试

- 插件 `test/review-fixes.test.mjs`：承诺 / 否定勾选框不勾、用户取消的勾保持；最低字数不截断、区间同时给出上下限、富文本框句末截断；在读学历的毕业时间留空。
